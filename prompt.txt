# AI Finance Agent

## Project Overview

AI Finance Agent is a full-stack, AI-powered personal finance management platform.

The goal is to turn raw financial data such as bank statements and receipts into structured transactions, financial analytics, forecasts, recommendations, and natural-language answers.

Users can upload bank CSV statements or receipts, and the system processes the data, categorizes transactions, stores them securely per user, and provides financial insights through a dashboard and AI finance agent.

The application is designed as a multi-user system with authentication, user-level data isolation, financial calculations, AI-powered analysis, and a React frontend.

## What the Application Does

### 1. Bank Statement Import

Users can upload bank CSV statements.

The backend:

* Parses CSV files using Pandas.
* Normalizes transaction data.
* Validates financial values.
* Automatically categorizes transactions using AI.
* Stores transactions in the user's account.

### 2. Receipt Processing

Users can upload receipt images.

The system:

* Processes receipts using OCR/Tesseract.
* Extracts merchant, date, amount, and other transaction information.
* Uses AI where appropriate to improve extraction/categorization.
* Saves the result as a cash expense.

### 3. AI Finance Agent

Users can ask natural-language questions about their finances.

Examples:

* "How much did I spend on food?"
* "How much did I spend at Starbucks?"
* "What were my biggest expenses this month?"
* "What are my recurring bills?"
* "How am I doing with my savings goal?"

The AI agent uses user-scoped tools to query financial data instead of relying purely on the language model's memory.

### 4. Financial Dashboard

The dashboard provides:

* Income
* Expenses
* Net cash flow
* Category spending
* Spending trends
* Date-range analytics
* Forecasts
* Savings goals
* Financial health information

Users can analyze different time periods.

### 5. Transaction Management

Users can:

* Search transactions.
* Filter transactions.
* Edit transactions.
* Delete transactions.
* Correct categories.
* Manage recurring status.

Transactions are isolated by authenticated user.

### 6. Recurring Transaction Detection

The system identifies recurring transactions/subscriptions.

Users can:

* View recurring transactions.
* Confirm recurring transactions.
* Remove confirmation.
* Distinguish AI-detected recurring transactions from user-confirmed recurring transactions.

### 7. Budget Management

Users can create spending budgets and monitor their spending against category limits.

The system can identify when spending approaches or exceeds budget thresholds.

### 8. Anomaly Detection

The system identifies potentially unusual transactions such as:

* Large unexpected expenses.
* Price increases.
* Duplicate charges.
* Unusual spending behavior.

### 9. Spending Forecasting

The system forecasts month-end spending using historical transaction data.

The forecasting system includes:

* Historical spending
* Moving averages
* Daily run-rate projections
* Blended forecasting
* Insufficient-data handling

Forecast calculations are deterministic and use financial data rather than allowing the AI to invent values.

### 10. Savings Goals

Users can create savings goals with:

* Goal name
* Target amount
* Current amount
* Target date
* Contributions
* Progress percentage
* Projected completion

Goals are user-scoped.

### 11. Financial Health Score

The system calculates a transparent financial health score using measurable components such as:

* Savings rate
* Budget adherence
* Income stability
* Spending consistency

The scoring methodology is deterministic and documented rather than being an arbitrary AI-generated score.

### 12. What-If Simulation

Users can simulate changes to their spending.

For example:

"If I reduce food spending by 20%, how much could I save?"

The system estimates the long-term effect of the simulated spending reduction.

## Security Architecture

The application supports multi-user authentication and user-level data isolation.

Security features include:

* JWT authentication
* JWT `jti`
* Server-side token revocation
* HttpOnly authentication cookies
* Secure production cookies
* SameSite protection
* CORS configuration
* Rate limiting
* Security headers
* Password validation
* Environment-based secrets
* Global API exception handling
* User-scoped database queries
* Secure file upload handling

JWTs are not stored in browser localStorage.

## AI Technology

The project uses Google Gemini for AI functionality.

AI is used for:

* Transaction categorization
* Receipt understanding/extraction
* Natural-language financial Q&A
* Finance-agent tool usage
* Financial explanations and recommendations

Important architecture principle:

The AI should explain and reason over deterministic financial calculations rather than inventing financial numbers.

For example:

Transaction data
→ Backend calculation
→ Verified financial result
→ AI explanation

rather than:

Transaction data
→ LLM guesses a number

## Main Project Goal

The overall goal is to build an intelligent personal finance assistant that does more than display transactions.

It should help users:

1. Understand where their money goes.
2. Ask questions about their financial history.
3. Detect unusual spending.
4. Identify recurring expenses.
5. Forecast future spending.
6. Manage budgets.
7. Track savings goals.
8. Understand overall financial health.
9. Eventually receive personalized, data-backed savings recommendations.

The core design principle is:

**Use deterministic backend calculations for financial facts and use AI primarily for understanding, reasoning, explanation, and natural-language interaction.**
